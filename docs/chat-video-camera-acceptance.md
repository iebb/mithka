## 收发路径和设备差异

聊天输入栏打开录像页。停止后，裁剪服务把输出文件或原片交给视频预览页；确认后，聊天模型向 TDLib 提交本地文件。接收端解析视频消息，在圆形气泡里展示缩略图或循环视频，点按走视频播放入口。

倍率指当前相机会话的 zoom 参数。插件没有提供每一帧的有效焦距或合焦确认。iOS 在上报镜头类型时可按广角、超广角和长焦选择。锁定版本的 Android CameraX 插件提供方向和 Camera2 ID，可能缺少镜头类型。在后置候选中，ID 0 仅作为未知镜头的优先线索；相同优先级沿用系统枚举顺序。部分机型的物理镜头归属仍需对照系统相机。

iOS 有原生方形导出。Android 的原生裁剪器目前返回 unsupported，应用回退到原片，接收端以圆形取景显示。两端实际导出、传输和解码都需用真实视频验证。

## 真机验收清单

优先使用最初复现问题的手机，再选一部采用另一平台的多摄手机。每次记录机型、系统、分支提交、方向、显示档位、操作步骤和结果；焦点和视野问题附同位置的系统相机对照画面。

| 待验 | 操作 | 通过条件 |
| --- | --- | --- |
| ☐ 首开与权限 | 从聊天窗首次打开，分别测试允许和拒绝相机、麦克风，再授权重开 | 授权后有连续预览，失败有可读提示，重新打开可用 |
| ☐ 后置默认视野 | 固定手机位置，用系统相机普通录像 1× 和聊天后摄拍同一远处目标，反复翻转 | 切回后置稳定回到接近 1× 的支持档；排除画幅裁切后无明显长焦放大 |
| ☐ 倍率与布局 | 横竖屏遍历前后摄所有显示档位，再试固定倍率镜头 | 选中态与画面变化相符；固定镜头不显示倍率；关闭和快门均可点 |
| ☐ 点按与曝光 | 前后摄分别对准近处文字、远处标识，在左、右偏心位置点按，改变照明 | 支持的镜头在可对焦距离内能合焦并适应明暗，特别核对自拍镜像和旋转后焦点 |
| ☐ 录像中调整 | 锁定录像后切换倍率、点按、暂停和恢复，同时录入人声 | 时长推进符合暂停状态，成片连续，无黑帧、意外停止或音画错位 |
| ☐ 手势与中断 | 长按松手、上滑锁定、左滑取消；分别在启动、录像、停止时返回，切后台再恢复，立即重开 | 正常释放或按已有策略取消；无后台继续录制、误发送、卡在加载或相机占用 |
| ☐ 裁剪和预览 | 录制画面边缘有标记的视频，停止后回看，分别确认和取消 | iOS 核对方形导出和方向；Android 核对原片回退和圆形显示；取消后聊天中没有该消息 |
| ☐ 端到端收发 | 经测试账号明确确认发送，由另一账号在 Android 和 iOS 端接收并点开回放 | 目标聊天、时长、方向、圆形构图、声音正确，下载后可播放，回看保留变焦过程 |
