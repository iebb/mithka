# Country flags

Generated by `tool/build_flag_sprite.py` from [Tossface](https://github.com/toss/tossface).

A 26x26 grid of 26pt cells covering every ISO
alpha-2 code. A flag's cell is its two letters — column from the
first, row from the second — so nothing here needs an index and
adding a country is a regenerate, not a table edit.

258 of 676 cells carry artwork; the rest
are transparent, which is the right fallback for a code that is not
a country.
